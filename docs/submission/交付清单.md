## 八、答辩现场提醒

| 场景 | 准备 |
|---|---|
| 断网 | `.env` 设 `MEDAI_DEMO_AI=1`，AI 走本地模拟流，全链路仍可演示 |
| 忘记密码 | 登录页有「用演示账号直接进去」（需 `MEDAI_DEMO_LOGIN=1`） |
| 电脑没装 Node | 提前装 Node 20+，或带离线包 + 一台备用机 |
| 数据被改乱 | 提前跑 `npm run db:backup`，讲完可以恢复 |
| 被问"你们的 RAG 呢" | 如实说：做了检索增强但用的是关键词方案，不是向量库，理由见技术文档 4.1 |
